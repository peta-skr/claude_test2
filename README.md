# AlgoViz — アルゴリズム可視化学習サイト

様々なアルゴリズムをインタラクティブに可視化して学べる学習サイトです。
ソート・探索・経路探索の代表的なアルゴリズムを、ステップごとのアニメーションで観察できます。

**ビルド不要・依存ライブラリなし** の純粋な HTML / CSS / Vanilla JavaScript で構築されています。

## 収録アルゴリズム

### 📊 ソート (`sorting.html`)
棒グラフの並び替えを可視化。比較・交換回数と経過時間をリアルタイム計測します。
**タイムライン制御**で再生・一時停止・1ステップ前後の移動・スクラブができます。

- バブルソート / カクテルソート / 選択ソート / 挿入ソート
- シェルソート / マージソート / クイックソート / ヒープソート

### 🔍 探索 (`searching.html`)
配列から目的の値を探す過程を可視化。探索範囲の絞り込みを色分け表示します。

- 線形探索 (Linear Search)
- 二分探索 (Binary Search)

### 🗺️ 経路探索 (`pathfinding.html`)
グリッド上でマウスドラッグして壁や**重み地形（コスト5）**を描き、最短経路の探索過程を比較できます。迷路の自動生成にも対応。

- 幅優先探索 (BFS) / 深さ優先探索 (DFS) — 重みを無視
- ダイクストラ法 / A* (エースター) — 重みを考慮し総コスト最小の経路を発見
- 経路長・総コスト・訪問ノード数を表示し、重み対応/非対応の違いを体感

### 🌳 データ構造 (`structures.html`)
基本的なデータ構造の操作をアニメーションで可視化します。

- スタック (LIFO) — push / pop / peek
- キュー (FIFO) — enqueue / dequeue
- 二分探索木 (BST) — 挿入 / 探索 / 削除 / 巡回（中間順・前順・後順・レベル順）

### 🏁 ソートレース (`race.html`)
複数のソートアルゴリズムをまったく同じデータで同時に実行し、最も少ない操作数で完了するものを競わせます。1ステップ＝1操作で全員が同ペースに進み、総ステップ数の少なさで順位付け（🥇🥈🥉）します。

### 🔁 再帰の可視化 (`recursion.html`)
再帰アルゴリズムが自分自身を呼び出しながら問題を解く様子を可視化します。

- フィボナッチ呼び出し木 — 指数的な呼び出し爆発と、メモ化による劇的な削減を比較
- ハノイの塔 — 「n-1枚を退避 → 1枚を移動 → n-1枚を戻す」再帰と最短手数 2ⁿ−1 を可視化

## 特徴

- 各アルゴリズムに **疑似コード** と **計算量 (Big-O)** の解説付き
- 速度・データ量をスライダーで自由に調整
- 比較回数や訪問ノード数などの統計を表示
- **ライト / ダークテーマ切替**（右上のボタン・localStorage に保存）
- ソートは **タイムライン制御**（再生・一時停止・ステップ実行・スクラブ）に対応
- レスポンシブ対応
- タッチ操作にも対応（経路探索の壁描画）

## 使い方

サーバー不要です。`index.html` をブラウザで開くだけで動作します。

```bash
# そのまま開く
open index.html            # macOS
xdg-open index.html        # Linux

# もしくは簡易サーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

## ディレクトリ構成

```
.
├── index.html          # トップページ
├── sorting.html        # ソート可視化
├── searching.html      # 探索可視化
├── pathfinding.html    # 経路探索可視化（重み付き対応）
├── structures.html     # データ構造可視化
├── race.html           # ソートレース
├── recursion.html      # 再帰の可視化
├── css/
│   └── style.css       # 共通スタイル（ライト/ダークテーマ）
└── js/
    ├── theme.js        # テーマ切替（全ページ共通）
    ├── sortcore.js     # ソートアルゴリズム共通コア（sorting/race で共有）
    ├── sorting.js      # ソート可視化 + タイムライン
    ├── searching.js    # 探索アルゴリズム
    ├── pathfinding.js  # 経路探索アルゴリズム（重み付き）
    ├── structures.js   # スタック / キュー / 二分探索木
    ├── race.js         # ソートレース
    └── recursion.js    # フィボナッチ呼び出し木 / ハノイの塔
```
