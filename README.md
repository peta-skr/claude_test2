# AlgoViz — アルゴリズム可視化学習サイト

様々なアルゴリズムをインタラクティブに可視化して学べる学習サイトです。
ソート・探索・経路探索の代表的なアルゴリズムを、ステップごとのアニメーションで観察できます。

**ビルド不要・依存ライブラリなし** の純粋な HTML / CSS / Vanilla JavaScript で構築されています。

## 収録アルゴリズム

### 📊 ソート (`sorting.html`)
棒グラフの並び替えを可視化。比較・交換回数と経過時間をリアルタイム計測します。
**タイムライン制御**で再生・一時停止・1ステップ前後の移動・スクラブができます。

- バブルソート / カクテルソート / 選択ソート / 挿入ソート
- シェルソート / マージソート / クイックソート / ヒープソート

### 🔍 探索 (`searching.html`)
配列から目的の値を探す過程を可視化。探索範囲の絞り込みを色分け表示します。

- 線形探索 (Linear Search)
- 二分探索 (Binary Search)

### 🗺️ 経路探索 (`pathfinding.html`)
グリッド上でマウスドラッグして壁を描き、最短経路の探索過程を比較できます。迷路の自動生成にも対応。

- 幅優先探索 (BFS) / 深さ優先探索 (DFS)
- ダイクストラ法 / A* (エースター)

### 🌳 データ構造 (`structures.html`)
基本的なデータ構造の操作をアニメーションで可視化します。

- スタック (LIFO) — push / pop / peek
- キュー (FIFO) — enqueue / dequeue
- 二分探索木 (BST) — 挿入 / 探索 / 削除 / 巡回（中間順・前順・後順・レベル順）

## 特徴

- 各アルゴリズムに **疑似コード** と **計算量 (Big-O)** の解説付き
- 速度・データ量をスライダーで自由に調整
- 比較回数や訪問ノード数などの統計を表示
- **ライト / ダークテーマ切替**（右上のボタン・localStorage に保存）
- ソートは **タイムライン制御**（再生・一時停止・ステップ実行・スクラブ）に対応
- レスポンシブ対応
- タッチ操作にも対応（経路探索の壁描画）

## 使い方

サーバー不要です。`index.html` をブラウザで開くだけで動作します。

```bash
# そのまま開く
open index.html            # macOS
xdg-open index.html        # Linux

# もしくは簡易サーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

```
├── structures.html     # データ構造可視化

│   └── style.css       # 共通スタイル（ライト/ダークテーマ）

    ├── pathfinding.js  # 経路探索アルゴリズム
    └── structures.js   # スタック / キュー / 二分探索木
```
